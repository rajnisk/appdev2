# MAD 2 Bootcamp: Modern Application Development

A 8-module roadmap to learn the modern, decoupled stack using a **Task Management App** as the core example.

---

## The Modern Stack

| Technology | Purpose |
|------------|---------|
| **Vite & Vue 3** | Fast, reactive frontend |
| **Flask-RESTful** | Standalone API service |
| **JWT** | Stateless authentication |
| **Redis** | Caching and task queuing |
| **Celery** | Background workers |

---

## 8-Module Roadmap

| Module | Topic | Description |
|-----|-------|-------------|
| **Module 1** | [The Modern Stack](module1-stack.html) | Vite, Vue 3, and SFCs |
| **Module 2** | [The Interactive UI](module2-ui.html) | Directives, Props, and Events |
| **Module 3** | [The API Bridge](module3-api.html) | Flask-RESTful, CRUD, and CORS |
| **Module 4** | [The Session Switch](module4-jwt.html) | JWT Auth and localStorage |

| **Module 6** | [The Background Worker](module6-celery.html) | Celery, Redis, and Async tasks |
| **Module 7** | [The Visual Report](module7-reports.html) | CSV generation and Mail automation |
| **Module 8** | [Final Polish](module8-polish.html) | State Management and UI Feedback |

---

## What You'll Build

A **Modern Task Management App** that demonstrates:
1. A separate frontend talking to a backend via API.
2. Secure login using tokens.
3. Fast responses using caching.
4. Background processing for heavy tasks.
5. Automated reporting.

---

## Prerequisites

- Completion of MAD 1 (Flask, Jinja, SQLAlchemy)
- Node.js installed (for Vite/Vue)
- Redis server installed and running
