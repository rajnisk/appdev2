# MAD 2 Glossary

Here are the key terms you will encounter throughout the MAD 2 journey.

| Term | Definition |
|:---|:---|
| **SFC** | **Single File Component**. A `.vue` file containing HTML, JS, and CSS for a single part of the UI. |
| **Vite** | A modern, ultra-fast build tool and development server for frontend projects. |
| **REST API** | An architectural style for providing data to clients using standard HTTP methods. |
| **JSON** | **Javascript Object Notation**. The text-format used to send data between the browser and server. |
| **CORS** | **Cross-Origin Resource Sharing**. A security mechanism that allows or restricts requests from one domain to another. |
| **JWT** | **JSON Web Token**. A stateless authentication method using signed tokens instead of server-side sessions. |
| **Stateless** | A server design where each request must contain all the information needed to understand it (no memory of previous requests). |
| **Redis** | A fast, in-memory data store used for caching and as a message broker. |
| **Caching** | Storing the results of expensive operations in a fast-access location (like Redis) to improve speed. |
| **Async Task** | A task that runs in the background (e.g., via Celery) so the user doesn't have to wait for it to finish. |
| **Celery** | A powerful distributed task queue used to handle background workers in Python. |
| **Broker** | A middleman (like Redis) that passes messages between your Flask app and Celery workers. |
| **State** | The current "status" or "data" of your application (e.g., who is logged in, list of tasks). |
