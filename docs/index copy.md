# MAD 2 Bootcamp: Modern Web Stack

Welcome to the second stage of your application development journey. In MAD 1, we built a monolith where Flask handled everything. In **MAD 2**, we are splitting the brain (Frontend) from the body (Backend).

## Why MAD 2?

- **Decoupled Architecture**: Your frontend can be a mobile app, a website, or a watch app—all talking to the same API.
- **Performance**: We learn to handle heavy tasks without making the user wait.
- **Modern Standards**: This is how industry-grade applications are built today.
